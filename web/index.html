Install public beta v0.7.4

macOS & Linux
curl -fsSL https://get.traylinx.com/install.sh | bash

Downloads checksum-verified release artifacts. No Rust toolchain. Installs CLI, MCP server, tray, and tytusOS where supported.

Windows
powershell -c "irm https://get.traylinx.com/install.ps1 | iex"

One-line PowerShell installer. CLI works today; MSI, SmartScreen signing, and driver packaging remain GA gates.

What happens next

1

Install Tytus

Pulls the public beta release advertised by catalog.json, verifies SHA256, and puts tytus, tytus-mcp, tray, and shared-folder tools on PATH.

2

Run setup

tytus setup signs you in, connects your Traylinx account, provisions your pod, and checks health.

3

Use your pod

Open tytusOS at localhost:4242, run tytus chat, or point OpenClaw, Hermes, Claude Code, OpenCode, Gemini, and Cursor at the AIL gateway.
